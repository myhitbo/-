# 4. Bot — version 1 (validé)

> **Décision du 26 novembre 2026** — Le bot WhatsApp n'est pas construit pour l'instant : depuis octobre 2026, Meta fait payer chaque message envoyé par un bot. Il est remplacé par une **chaîne WhatsApp** gratuite, dont les messages sont préparés automatiquement : voir [11. Chaîne WhatsApp](11-chaine-whatsapp.md). Ce document reste la référence si un bot (Telegram, ou WhatsApp avec un budget) est décidé plus tard.

## Canaux
- WhatsApp en priorité, puis Telegram
- Compte partagé avec l'app

## Message du matin (heure choisie)
```
📖 Vayéra — Shlishi · environ 9 min
🔗 Lire dans l'app
Réponds ✅ quand c'est fait
```
Réponses possibles :
- **✅** : coche l'alya et met à jour la série
- **« plus tard »** : nouveau rappel 2 h après
- **« texte »** : l'alya est envoyée dans la conversation (verset, verset, Targoum)

## Messages automatiques
- **Jeudi soir** : alyot restantes + temps estimé
- **Vendredi** : Shabbat Shalom + compteur mondial + **petit dvar Torah traduit dans la langue de l'utilisateur**
- **Dimanche** : nouvelle paracha + bilan de la semaine + série
- **Groupe** : notification quand un membre termine (désactivable)

## Inscription
« Bonjour » au numéro, puis 3 questions : langue, Israël ou diaspora, heure du rappel.

## Règles
- Aucun message pendant Shabbat et les fêtes (selon le fuseau de chaque utilisateur)
- Au plus 1 message par jour, plus le rappel du jeudi
- WhatsApp : modèles de messages préapprouvés par Meta pour écrire en premier
